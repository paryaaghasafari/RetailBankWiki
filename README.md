# RetailBankWiki

[![Deploy MkDocs to GitHub Pages](https://github.com/paryaaghasafari/RetailBankWiki/actions/workflows/deploy.yml/badge.svg)](https://github.com/paryaaghasafari/RetailBankWiki/actions/workflows/deploy.yml)

**Live wiki: <https://paryaaghasafari.github.io/RetailBankWiki/>**

Fictional **Northvale Demo Bank** policy & compliance wiki corpus, built for a GenAI RAG capstone demo. All content is **fictional** and exists only to exercise retrieval, citation, and out-of-scope handling in a downstream RAG pipeline.

## What's in this repo

| Path | Purpose |
|---|---|
| `docs/Home.md`, `*-Policy.md`, `*-Procedures.md`, `*-Guidelines.md`, `*-Limits.md` | The 7 wiki pages (the embedding corpus) |
| `docs/_Sidebar.md` | GitHub-wiki-compatible navigation |
| `docs/attachments/` | 3 PDFs, 2 DOCX, 4 PNGs (generated by the scripts) |
| `scripts/generate_images.py` | Builds the 4 flowchart PNGs (matplotlib) |
| `scripts/generate_pdfs.py` | Builds the 3 PDFs with embedded PNGs (reportlab) |
| `scripts/generate_docx.py` | Builds the 2 DOCX files (python-docx) |
| `SEEDED-FACTS.md` | Canonical numeric facts + source citations for eval design |
| `EVAL-QUESTIONS.md` | **20 ground-truth Q&A** for testing the RAG team's citation accuracy |
| `LOAD-CORPUS.md` | Ingestion guidance for the team building the RAG pipeline |
| `mkdocs.yml` | MkDocs Material config - renders the wiki as a Wikipedia-style site |
| `pyproject.toml` + `.python-version` + `uv.lock` | uv-managed Python 3.11 environment |

## Quick start

```bash
# 1. Sync dependencies (uv installs Python 3.11 if needed)
uv sync

# 2. Generate the 9 binary attachments
uv run python scripts/generate_images.py
uv run python scripts/generate_pdfs.py
uv run python scripts/generate_docx.py

# 3. Browse the wiki as a Wikipedia-style site
uv run mkdocs serve
# -> http://127.0.0.1:8000
```

Requires `uv >= 0.4.0`.

## Deployment

The wiki auto-deploys to GitHub Pages on every push to `main` via `.github/workflows/deploy.yml`. The workflow:

1. Installs `uv` and syncs the Python 3.11 environment from `uv.lock`.
2. Runs the 3 generate scripts (idempotent — outputs match committed binaries unless a script changed).
3. Runs `uv run mkdocs build --strict` (build fails on broken links).
4. Uploads `site/` and deploys it via `actions/deploy-pages`.

**One-time setup**: in the GitHub repo settings, set **Settings → Pages → Build and deployment → Source = "GitHub Actions"**.

To trigger a manual deploy without pushing, go to **Actions → Deploy MkDocs to GitHub Pages → Run workflow**.

## For the RAG team building on this data

Read **`LOAD-CORPUS.md`** for the recommended ingestion approach (heading-aware chunking, metadata schema, file inclusions/exclusions) and **`EVAL-QUESTIONS.md`** for the 20-question ground-truth evaluation set with expected citations.

All references inside the wiki are **relative paths** to files in this repo - no external URLs. The whole folder is self-contained and can be zipped and handed off.

## Deliberately omitted topics

For out-of-scope eval testing, none of these are covered anywhere in the corpus:

- Cryptocurrency / digital assets
- Employee benefits / HR
- IT security / infosec / passwords / VPN

A correct RAG implementation should refuse to answer questions about these topics with a "not found in source documents" style message.
